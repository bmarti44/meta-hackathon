## Predeclared failure-charge rule (for any future measured-token comparison)
Primary resource unit (non-overlapping): TOK = input_tokens + output_tokens per call
(cached_input and reasoning_output are reported subcomponents, never added again).
Unmeasured call (failed/killed/timeout/missing usage) in an epoch is charged, per category,
max(measured values among completed calls of the same effort in that epoch); if none completed
yet, the epoch per-call cap (input 2,000,000; output 50,000) applies. Charging is symmetric
across arms and always >= any completed call of that effort (conservative against the arm that
incurred the failure). USD remains unknown; TOK is the proposed alternative endpoint under
handoff section 11, UNADJUDICATED until sol-high/xhigh review. CPU/wall measured via run_bounded.
