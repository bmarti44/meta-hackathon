Complete addressability = every admissible ID is reachable via header→partition→lookup, without ever rendering the whole directory. **Overflow outcome:** if no legal rendering fits the frozen token budget, the generation call splits further (finer sub-partitions, header unchanged) — if still infeasible, the SPEC must narrow its index scope explicitly and the narrowing is ledgered; silent truncation is forbidden. Fixtures required: directory-alone-exceeds-cap and single-direction-exceeds-cap cases both rendering legally. What each call received is recorded in its input manifest. This is the single definition of "full tried history" used in GOAL.md. The hidden-outcome invariance test (§0.4.2) must cover the **complete rendered input and resulting decisions**, all channels included.

    38	### 0.4 Trajectory system (Dream-RSI adaptation — departures disclosed)
    39	
    40	Adapted from Dream-RSI (arXiv:2609.14858; `google-research/dream-rsi`): discovery history as replay simulator; offline policy improvement ("dreaming") then online redeployment; fixed generator+evaluator+task, only policy changes. Spec constraints override the paper where they conflict; then the method is labeled **Dream-RSI-inspired adaptation**.
    41	
    42	**0.4.1 Units & DAG schema.** *Node/attempt* = one evaluated artifact. Every node has an **ordered parent array** (possibly empty, one, or many), forming an **acyclic** lineage DAG validated at insert. Each parent edge records the parent's immutable contribution (which components carried over). Nodes carry `study_id`, `evaluator_version`, `world_id` (the round/tree that produced them; recombination children belong to their birth world and reference parents across worlds by ID). **Replay eligibility:** a node is replayable in an episode only if (a) every information-bearing parent is either revealed earlier in the episode or in the initially-available set, (b) study/evaluator versions match the episode, and (c) its canonical input manifest matches the episode state (§0.4.6). **Ancestry cost** = cost of the union of required ancestor nodes, charged **once** per episode (Phase 5 allocation). *Branch/trajectory* = the primary-parent (first-parent) chain view of the DAG, used for best-so-far curves; *discovery tree* = one round's forest under one policy on one panel, frozen+hashed into the **trace pool** as a replay world (pool only grows). Tree shape `BRANCHES × (REFINE+1)` scaled to budget; exact values frozen at Lock 1. *Direction* = coherent research line over many nodes.
    43	
    44	*Identities (dedup done right, arm-scoped):* `attempt_id` · `context_hash` · `config_id` · `evaluation_id` (config × data × split × evaluator version). **Duplicate eligibility is computed only against the acting arm's episode-admissible history**, scoped by (study, panel, split): the same `config_id` under a new `evaluation_id` (genuinely new evidence/panel) is legal under the frozen symmetric-evaluation rule; re-running an existing `evaluation_id` *within the same arm scope* is a replication (prespecified reason required). The global artifact store retains bytes for audit, but **global membership never changes any arm's observations, rejections, or legal actions** (no existence-oracle across arms/episodes). Required tests: adding hidden/other-arm configs must not change an arm's behavior; reversing arm execution order must not change either arm's outcomes. Trial accounting uses these levels (§0.5.1.8).
    45	
    46	**0.4.2 Direction catalog with episode views.** `directions/catalog.json` + immutable snapshots (`history/iterNNN.json`). Status is **four independent fields**, each with deterministic predicates in a **total transition table frozen at Lock 1** (every state combination + missing-evidence + precedence + recovery transitions defined; each transition cites evidence node IDs): `depth` ∈ {unexplored, underexplored, explored, well_explored} · `promise` ∈ {unknown, unpromising, promising} · `fragility` ∈ {unknown, robust, fragile} · `recoverability` ∈ {n/a, recoverable, dead}. Derived labels (e.g. "saturated" = depth well_explored + marginal-gain < ε over last k attempts) are **resource-allocation judgments, never scientific exhaustion verdicts**. Catalog also stores: evidence attempt IDs, best/median quality, quality-vs-cost slope, failure taxonomy, `avoid_repeating`, bottlenecks. Extraction (sol-xhigh, schema-validated) proposes classifications; **deterministic predicates verify them** against recorded outcomes — mismatches rejected+ledgered.
    47	**Episode views (no future leakage):** anything fed to a policy/generator during replay — catalog snapshot, frontier, summaries, priorities, legal actions — is **recomputed from admissible history only**: complete earlier worlds + the revealed prefix of the current world. Global/current catalog objects never enter replay. Acceptance test: mutating any unrevealed outcome must not change any episode-view artifact or policy decision (hidden-outcome invariance test).
    48	
    49	**0.4.3 Trajectory scoring (formal, deterministic, no LLM).** Locked at Lock 1 with formulas; defaults: per-node **valid quality** `q ∈ [0,1]` = locked monotone transform of the primary scientific endpoint (higher = better; sign/direction fixed in contract; invalid ⇒ no q, counted invalid, never 0-as-quality). Per trajectory with cumulative measured cost `c`: best-valid-so-far `B(c) = max q over valid nodes with cumulative cost ≤ c` (0 if none); **cost-to-threshold** `C(τ) = min c with B(c) ≥ τ`, else **censored at budget** (never an invented number); **normalized area-over-curve** `AoC = (1/B_ep) ∫₀^{B_ep} B(c) dc` over the episode budget `B_ep`; validity rate; **robustness** `R` = locked sensitivity statistic (e.g. min quality retained across prespecified sensitivity replicates, formula at Lock 1). **Pareto frontier** computed **within a comparable domain** (same task panel + evaluator version + endpoint) over (final B, total cost, R). Precedence: frontier membership = evidence quality; saturation/pruning = allocation status — a nondominated-but-saturated trajectory stays frontier-listed but allocation-paused; neither label overwrites the other.
    50	
    51	**0.4.4 Origins & generation.** Sol-xhigh proposes candidates under the frozen protocol (§0.1); each declares exactly one node-operation/origin:
    52	- `new` (0 parents; opens unexplored direction) · `refinement` (exactly 1 parent; mutate/extend a frontier or winner artifact) · `underexplored_extension` (1+ parents in a thin-evidence direction) · `combination` (≥2 parents; each contribution stated; legality of each element checked; revalidated from scratch; no score inheritance) · `repair` (≥1 parent + cited failure node ID + named fix).
    53	Runner rejects (ledgered, fed back next round): outside locked spaces; duplicate `config_id` without replication authorization; nonexistent parents/evidence; `avoid_repeating` repeats without `repair` justification; cyclic or version-incompatible lineage.
    54	
    55	**0.4.5 Selection = executable policy over prefix-recomputed state.** Proposal (sol-xhigh: what *could* run + priorities as inputs) ≠ selection (versioned `policy(episode_view, legal_actions, remaining_budget) → action`). **Legal actions are recomputed at each step from the revealed prefix** using frozen transition/pruning rules — historical legal-action sequences are audit records, never counterfactual state for challengers. Keep/prune: frontier trajectories refinable; allocation-paused (saturated) directions leave the legal set until a frozen reactivation rule fires; `fragile` trajectories refinable only via prespecified robustness diagnostics. Deterministic recomputation covers all code-computed state. **LLM-produced state** (direction summaries, rankings, proposals, extraction text) is **immutable memoized output**: stored content-addressed, keyed by (canonical admissible-state hash, generator-protocol version); replay/offline reconstruction **reads the memo — never re-invokes the model**. Cache miss during replay ⇒ that transition is `unsupported` (online execution may create the memo, charged once at creation, then reused). Required test: repeated reconstruction from the same revealed outcomes yields byte-identical rendered inputs with zero additional model calls. Catalog *classifications* remain predicate-verified deterministically (§0.4.2); free-text summaries/rankings are memo-replayed, not regenerated.
    56	
    57	**0.4.6 Dreaming: replay objective, ρ, exact context, common support.**
    58	- **ρ is a budget-control parameter** (as in the paper): replay evaluates each policy at operating budgets `ρ·B_ep` for ρ ∈ {0, 0.25, 0.5, 0.75, 1}. **Replay objective (complete formula frozen at Lock 1; default):** per episode e and ρ, `J_e(π,ρ) = B_e(ρ·B_ep)` (best valid quality attained within that budget; invalid nodes contribute cost, no quality; zero-attainment ⇒ 0). Policy score `J(π) = Σ_ρ w_ρ · mean_e J_e(π,ρ)` over the **common eligible episode set** (below) with locked weights `w_ρ` (default uniform). **Total ordering (frozen before replay; no residual ties):** (1) higher J; (2) higher attainment fraction `P(B_e(B_ep) ≥ τ)`; (3) lower **restricted-mean cost-to-τ** `mean_e min(C_e(τ), B_ep)` (identifiable under censoring); (4) earlier position in the SPEC's pre-listed candidate order; (5) lexicographically smaller immutable candidate ID. The incumbent participates as an ordinary candidate in this ordering; "retain incumbent" is simply the outcome when the incumbent orders first — never an extra discretionary step. Costs are measured ledger costs (§0.4.1 ancestry rule); endpoints' signs/scales per contract.
    59	- **Exact context (operational; history-dependent, not "parent-local"):** refinement generation is **history-dependent exact-context replay** — the generator's inputs are exactly its canonical manifest (parent artifact(s) + frozen instruction + episode-view snapshot ID + budget token + retrieved records). A recorded child replays **iff** the challenger's episode state reproduces that manifest hash exactly; **any differing input ⇒ `unsupported`**, never approximated. Before any screening reliance, Phase 3/4 must **measure attainable support on reordered traces** (including context-overflow and budget-token variation) and report it; if attainable support fails §below thresholds, replay screening is inadmissible by construction for that comparison.
    60	- **Common support (frozen at Lock 1; no policy-specific deletion):** for each ρ separately, an episode is **fully supported for policy π at ρ** if every decision π requests within budget `ρ·B_ep` replays as supported. The **common eligible set at ρ** = episodes fully supported for **every** compared policy at that ρ (intersection; fixed episode-level denominator = the frozen episode list size, never trajectory-length-dependent). `J_e` means are computed **only on the common eligible set, identically for all policies** — policies are never ranked on different surviving sets. **Adequacy:** if the common set at any ρ with `w_ρ > 0` falls below the locked threshold (default ≥ 8 episodes **and** ≥ 50% of the frozen list), the screen is **inadmissible** for that comparison → fresh rollouts decide (§Phase 4 fallback). Unsupported actions terminate that policy's episode copy as `unsupported` (removing the episode from the common set for everyone at that ρ, reported per-policy as the cause) and can **never** count as cheap successful stops. Coverage (per policy, per ρ) always reported beside scores.
    61	- Both arms share the same first round **E0** (starting policy; copied read-only; its production cost charged per Phase 5 allocation — copying is not free).
    62	
    63	**0.4.7 Audit views.** `status --trajectories`: lineage DAG (all parents), direction board (4-field statuses), frontier data, generation-over-generation table, allocation-paused list + reasons, coverage reports. Derived deterministically from ledgers; ledger wins on disagreement (= view bug).

    65	### 0.5 Generation protocol (adapted from the business LOOP, hardened)
    66	
    67	Modeled on `~/bufferright/business/data/research/paths/LOOP/` (48 generations; "Sol xhigh proposes, Sol high reviews"; score trails 54→76→92). Translation: sleeve pool → analysis-family pool; blend → `combination`; PREREG hash → SPEC hash; forward ledger → frozen predictions; anchor → evaluator-compatibility suite (below). **Two separate lifecycles** (never mixed): **(S) scientific-artifact generations** and **(P) policy generations**, each with own SPEC, screen, battery, denominators, trial counters.
    68	
    69	**0.5.1 Anatomy (`generations/{s,p}genNNN/`, never reused/overwritten).**
    70	1. **SPEC.md + SHA-256 locked in ledger before any run:** discriminating question, candidate families, screen definition (incl. whether it is a *necessary-condition* screen — §0.5.2), battery definition, pass bar, stop rules, reserved battery budget. Amendments = new versioned files; locked-science amendments follow new-study-ID rule.
    71	2. **Enumerate** from the pool under frozen protocol; origins+parents per §0.4.4; legality validated.
    72	3. **Screen (ranking only, labeled approximate).** Screen-positives are never claims.
    73	4. **Recombine/refine winners** (`combination`/`refinement`); re-enter at screen; no score inheritance.
    74	5. **Battery (decisive):** (S) full frozen evaluator + validity + matched controls + ablations on fresh development rollouts; (P) Phase 4/5 procedure (replay screen → fresh paired rollouts incl. incumbent). Battery budget is **reserved before screening**; if ceilings intervene, unfinished batteries are `PENDING`, never silently dropped.
    75	6. **Verdicts are scoped to what was tested:** `ADVANCES` · `FAILS-BATTERY (tested finalists: n/N, with numbers)` · `FAMILY-CLOSED` (allowed **only** with a proven necessary-condition screen or exhaustive battery — §0.5.2; else untested members remain explicitly open) · `INVALID` (defective record preserved, corrected in a new version) · `BLOCKED-DATA` (no proxy substitution without claim downgrade) · `PENDING`.
    76	7. **Sol-high review → verify → fix → re-review to ≥ 90**, per-issue dispositions (`CONFIRMED+FIXED` / `ACCEPTED with claim downgrade` / `REJECTED with evidence`).
    77	8. **`GENERATIONS.md` entry:** numbers for every finalist incl. failures, lessons, next mandate, stop-rule checks (leakage ⇒ dependent lines cancelled), and **multi-counter trial accounting** (cumulative, separate: unique configs, attempts, replications, hypothesis inspections, policy candidates, replay episodes, batteries — scientific vs engineering adaptation never merged into one total; no count substitutes for confirmatory procedure).
    78	
    79	**0.5.2 Screening honesty.** A screen justifies exhaustive rejection **only** if passing it is a mathematically necessary condition for passing the battery (proof stated in SPEC, e.g. battery metric is a monotone refinement bounded by the screen metric). Otherwise verdicts read "no *tested finalist* passes" and screen-negative members stay listed as untested. Cheapest-falsification probes run as one fixed SPEC with no variants; failure closes only the tested specification, with family-level closure requiring the necessary-condition argument.
    80	
    81	**0.5.3 Evaluator versioning (anchor is not certification).** Scores from different evaluator versions are **never pooled** in one comparison/replay pool. The frozen baseline "anchor" reproduction is a smoke check only. Any evaluator change requires: compatibility suite (rankings + validity decisions on a frozen probe set), explicit invalidation list for affected results, and — if substantive — the new-study/new-evidence procedure. Versions preserved side-by-side.
    82	
    83	**0.5.4 Matched controls & post-hoc rule.** A new ingredient is credited only vs a same-construction control lacking it; unmatched construction changes are disclosed as non-decomposable. Post-hoc discoveries (e.g. control beats hypothesis) are flagged post-hoc, may be frozen for forward judging, never promotable on consumed data.
    84	
    85	**0.5.5 Generation boundary (end-to-end).** Deterministic scores/frontier/episode views → sol-xhigh direction summary + ranked proposal (keep / recombine-with-rationale / repair / open / pause, all ID-cited) → policy code executes selection under budget → runs → extraction + predicate verification → sol-high ≥ 90 → ledger + trace-pool append.

    87	### 0.6 Autonomy, unstick protocol, campaign limits & terminal determination
    88	- **Default = continue autonomously** through failures/negative results, generation after generation, **within campaign allocations** (Lock 1: per-phase + total wall/nodes/model-calls, inside §0.2 ceilings). Legitimate stops: hard authorization gate (credential/spending/required file), allocation/ceiling exhaustion, explicit user stop, no-progress determination (below), terminal determination.
    89	- **Unstick (sol-xhigh):** on stall (no obvious legal action, unexpected gate failure, all directions paused/dead/blocked, contradictory results, same failure twice) invoke sol-xhigh with the state packet (STATUS, episode views, frontier, last 3 generation entries, blocker + attempts) for ranked unblocks + cheapest discriminating experiment + draft next SPEC. Verify vs locked contract (sol cannot authorize contract/ceiling/final-access/standard changes); ledger consultation+disposition; **unstick calls are charged costs** (Phase 5). Max 3 consultation rounds per blocker, then smallest legal evidence-gathering action. Under a frozen comparison, unstick input is restricted to that arm's admissible history (§0.1 freeze).
    90	- **No-progress / negative-EV rule (prevents indefinite retries, spec §14):** applies **before Lock 1 too**, against §0.2 pre-lock allocations: a pre-lock blocker (crosswalk, pairing, review gate) surviving its repeat-failure limit, or K consecutive generations (K default 3, finalized at Lock 1) with no frontier movement / new identifiable question / gate progress, triggers joint sol-xhigh + lead assessment; concurrence ⇒ admissible **non-complete terminal determination** (`INCONCLUSIVE`/`BLOCKED`) with unmet gates + smallest next step. Gate reviews exceeding the Phase-0 round cap escalate to the user with the residual issue list rather than looping.
    91	- **Terminal determination (sol-xhigh judges, evidence rules):** `COMPLETE_*` requires sol-xhigh's written gate-by-gate (C1–C13) certification over the full evidence package, score ≥ 90, zero unresolved high/critical — **in addition to** the evidence, never instead of it; it cannot waive gates. A **pre-reserved terminal-review budget slice** (Lock 1) guarantees the call is affordable; if it still cannot run, the executor may mechanically checkpoint and report `BLOCKED`/`BUDGET_EXHAUSTED` honestly — but **positive completion always requires the sol-xhigh determination**. Non-complete determinations list exact unmet gates; consumed Layer-B/C evidence stays consumed (Phases 5–6).

    50	def partial_spearman(y: np.ndarray, x: np.ndarray, z: np.ndarray) -> float:
    51	    """Pearson correlation of rank residuals (THE locked operation)."""
    52	    def resid(a, b):
    53	        ra, rb = pd.Series(a).rank().values.astype(float), pd.Series(b).rank().values.astype(float)
    54	        X = np.column_stack([np.ones_like(rb), rb])
    55	        beta, *_ = np.linalg.lstsq(X, ra, rcond=None)
    56	        return ra - X @ beta
    57	    return float(np.corrcoef(resid(y, z), resid(x, z))[0, 1])

     9	    """Return list of violations (empty = legal). existing: attempt_id -> node."""

    32	    """Pearson correlation of rank residuals (exact operation, locked here)."""
    33	    def resid(a, b):
