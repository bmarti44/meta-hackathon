    53	def _rank_resid(a: np.ndarray, Z: np.ndarray) -> np.ndarray:
    54	    ra = pd.Series(a).rank().values.astype(float)
    55	    if not np.isfinite(ra).all() or ra.std() < RANK_RESID_TOL:
    56	        raise ValueError("degenerate ranks (constant or nonfinite input)")
    57	    Rz = np.column_stack([pd.Series(Z[:, j]).rank().values.astype(float) for j in range(Z.shape[1])])
    58	    if not np.isfinite(Rz).all():
    59	        raise ValueError("nonfinite covariate")
    60	    X = np.column_stack([np.ones(len(ra)), Rz])
    61	    beta, *_ = np.linalg.lstsq(X, ra, rcond=None)
    62	    r = ra - X @ beta
    63	    if not np.isfinite(r).all() or r.std() < RANK_RESID_TOL:
    64	        raise ValueError("degenerate rank residuals")
    65	    return r

    68	def partial_spearman(y: np.ndarray, x: np.ndarray, z: np.ndarray) -> float:
    69	    """Pearson correlation of rank residuals (THE locked operation).
    70	
    71	    z may be 1-D (single covariate) or 2-D (simultaneous adjustment).
    72	    Raises ValueError on constant/nonfinite/degenerate inputs.
    73	    """
    74	    Z = np.asarray(z, dtype=float)
    75	    if Z.ndim == 1:
    76	        Z = Z.reshape(-1, 1)
    77	    return float(np.corrcoef(_rank_resid(np.asarray(y, dtype=float), Z),
    78	                              _rank_resid(np.asarray(x, dtype=float), Z))[0, 1])

../PLAN.md:49:**0.4.3 Trajectory scoring (formal, deterministic, no LLM).** Locked at Lock 1 with formulas; defaults: per-node **valid quality** `q ∈ [0,1]` = locked monotone transform of the primary scientific endpoint (higher = better; sign/direction fixed in contract; invalid ⇒ no q, counted invalid, never 0-as-quality). Per trajectory with cumulative measured cost `c`: best-valid-so-far `B(c) = max q over valid nodes with cumulative cost ≤ c` (0 if none); **cost-to-threshold** `C(τ) = min c with B(c) ≥ τ`, else **censored at budget** (never an invented number); **normalized area-over-curve** `AoC = (1/B_ep) ∫₀^{B_ep} B(c) dc` over the episode budget `B_ep`; validity rate; **robustness** `R` = locked sensitivity statistic (e.g. min quality retained across prespecified sensitivity replicates, formula at Lock 1). **Pareto frontier** computed **within a comparable domain** (same task panel + evaluator version + endpoint) over (final B, total cost, R). Precedence: frontier membership = evidence quality; saturation/pruning = allocation status — a nondominated-but-saturated trajectory stays frontier-listed but allocation-paused; neither label overwrites the other.
../PLAN.md:58:- **ρ is a budget-control parameter** (as in the paper): replay evaluates each policy at operating budgets `ρ·B_ep` for ρ ∈ {0, 0.25, 0.5, 0.75, 1}. **Replay objective (complete formula frozen at Lock 1; default):** per episode e and ρ, `J_e(π,ρ) = B_e(ρ·B_ep)` (best valid quality attained within that budget; invalid nodes contribute cost, no quality; zero-attainment ⇒ 0). Policy score `J(π) = Σ_ρ w_ρ · mean_e J_e(π,ρ)` over the **common eligible episode set** (below) with locked weights `w_ρ` (default uniform). **Total ordering (frozen before replay; no residual ties):** (1) higher J; (2) higher attainment fraction `P(B_e(B_ep) ≥ τ)`; (3) lower **restricted-mean cost-to-τ** `mean_e min(C_e(τ), B_ep)` (identifiable under censoring); (4) earlier position in the SPEC's pre-listed candidate order; (5) lexicographically smaller immutable candidate ID. The incumbent participates as an ordinary candidate in this ordering; "retain incumbent" is simply the outcome when the incumbent orders first — never an extra discretionary step. Costs are measured ledger costs (§0.4.1 ancestry rule); endpoints' signs/scales per contract.
../PLAN.md:60:- **Common support (frozen at Lock 1; no policy-specific deletion):** for each ρ separately, an episode is **fully supported for policy π at ρ** if every decision π requests within budget `ρ·B_ep` replays as supported. The **common eligible set at ρ** = episodes fully supported for **every** compared policy at that ρ (intersection; fixed episode-level denominator = the frozen episode list size, never trajectory-length-dependent). `J_e` means are computed **only on the common eligible set, identically for all policies** — policies are never ranked on different surviving sets. **Adequacy:** if the common set at any ρ with `w_ρ > 0` falls below the locked threshold (default ≥ 8 episodes **and** ≥ 50% of the frozen list), the screen is **inadmissible** for that comparison → fresh rollouts decide (§Phase 4 fallback). Unsupported actions terminate that policy's episode copy as `unsupported` (removing the episode from the common set for everyone at that ρ, reported per-policy as the cause) and can **never** count as cheap successful stops. Coverage (per policy, per ρ) always reported beside scores.
